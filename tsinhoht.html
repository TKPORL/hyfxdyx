    ① 应用到前台预览

    把当前改动保存到本浏览器，打开首页立即看到效果（仅本人可见，用于发布前检查）。

    ② 一键发布到 GitHub（推荐）

    把当前改动直接提交到仓库 data/games.override.json，云端爬虫自动合并后 1~3 分钟全站生效。需先在「设置」配置 GitHub Token。

    ③ 导出 games.json（全量备份）

    导出完整站点数据文件。注意：直接替换 data/games.json 会被下一次自动同步覆盖，建议用②。

    ④ 导入 JSON 数据

    导入之前导出的 games.json / games.override.json 或任意符合格式的数据文件，导入后可继续编辑。

    ⑤ 恢复官方同步数据

    丢弃所有本地覆盖与改动，回到 data/games.json 的原始爬取数据（不可撤销，请先导出备份）。

    首页公告编辑

    保存后：① 打开首页立即预览（仅本浏览器）；② 数据管理 →「保存并发布」一步全站生效（约 1~3 分钟）。

    GitHub Token（一键发布 + 图床上传共用）

    配置后可用「发布到 GitHub」一步把改动提交到仓库；也可在编辑游戏时上传本地图片到仓库 assets/admin/ 并自动转成 jsDelivr 直链。Token 只保存在本浏览器。

    评论管理 Token（回复 / 删除 / 置顶评论用）

    获取方式：在 Supabase SQL Editor 运行仓库里的 supabase_hyfx.sql（会自动生成一个随机 Token）， 再执行 select token from admin_tokens; 复制结果粘贴到这里。

    修改后台密码

    密码保存在浏览器本地（localStorage），仅保护此浏览器的后台入口；请勿在公共电脑登录。
