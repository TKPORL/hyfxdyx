    首页公告编辑

    保存后：① 数据管理 →「保存并应用」可立即在前台预览；② 「导出 Override」提交仓库后全站生效。

    图床上传（GitHub 仓库直链）

    配置后，在「游戏管理」新增/编辑弹窗里点「上传本地图片」即可把图片提交到仓库 assets/admin/ 目录并自动转成 jsDelivr 直链填入表单；首次上传会触发一次自动部署，新链接若短暂打不开是 CDN 缓存延迟。

    修改后台密码

    密码保存在浏览器本地（localStorage），仅保护此浏览器的后台入口；后台页面本身无服务器，请勿在公共电脑登录。

    关于本后台

    本后台为纯静态页面，配合 GitHub Pages 使用：
    1. 改动先保存在浏览器 → 前台即时预览；
    2. 确认无误后「导出 games.override.json」并提交到仓库 data/ 目录；
    3. 爬虫每次自动同步时会合并该文件：同 ID 覆盖、新 ID 追加到最前、remove_ids 中的条目被移除；
    4. 想彻底放弃某条删除标记，可在「恢复官方数据」后重新导出空的 override 文件。
