第一步：装解压软件

电脑 装 7-Zip 或 Bandizip（都免费），不装就打不开压缩包
手机 装 ZArchiver（免费），应用商店或官网都能下

按文件类型解压

exe 一般直接双击解压；个别是伪装后缀的，改成 zip 或 rar 再解压
tar 文件直接解压
分卷 全部分卷放同一个文件夹里，只解压 part1（第一卷）
psd、jpg 文件后缀改成 rar 后解压
00、txt 文件后缀改成 rar 解压
mp4 后缀改成 zip 或 rar 解压（先下载到本地，勿在线解压）
改后缀前：先让电脑显示文件后缀
Windows 默认隐藏后缀，不改设置的话你改的其实不是真后缀（会变成 xxx.mp4.txt）：
Win10　打开文件资源管理器 → 顶部「查看」→ 勾选「文件扩展名」。
Win11　文件资源管理器 → 顶部「查看」→ 「显示」→ 勾选「文件扩展名」。
手机不用设置，ZArchiver 里长按文件 → 重命名，直接把后缀改掉就行。

手机（安卓）解压

流程和电脑一样，只是换成在 ZArchiver 里操作：
解压　打开 ZArchiver 找到下载的压缩包，点它 → 「解压到当前目录」。
改后缀　mp4 / exe 这类伪装文件：长按 → 重命名，把后缀改成 zip 或 rar，再点开解压。
分卷　所有分卷放同一个文件夹，点第一个解压。
安装游戏　解压出 apk 就点开安装；解压出数据包文件夹的，按游戏说明放到指定目录。
手机管家报毒是误报常见，在管家里加信任即可；别用网盘在线解压，先下载到手机再操作。

解压密码

无
下载前看一眼游戏介绍，某些游戏可能有

提示压缩包损坏

打开压缩包，还报错就重新下载。

如果没有报错，就直接拉出压缩包文件。

常见问题

密码 通常写在资源来源页、帖子说明或同目录 txt 中，注意全角 / 半角、大小写
CRC 错误 文件损坏，重新下载（优先换做种多的源）
报毒 / exe 被删 多为误报：先关闭杀毒实时防护或把游戏文件夹加信任，再重新解压
路径太长 把压缩包移动到较短路径（如 D:\game\）再解压
文件名乱码 解压时把编码设为日文（Shift-JIS），或先转区再解压
日文游戏乱码 / 双击没反应 / 闪退
这是「非 Unicode 程序语言」不是日语导致的。三种办法任选其一：
Locale Emulator（推荐）　解压后运行 LEInstaller.exe 注册右键菜单，之后右键游戏 exe → Locale Emulator → Run in Japanese。
NTLEA　另一款转区工具，用法类似。
改系统区域　控制面板 → 区域 → 「管理」→ 更改系统区域设置 → 「非 Unicode 程序语言」设为日语（日本） → 重启（一劳永逸）。
转区工具行为特殊，杀软可能误报，从本站镜像或官方源下载即可。
下载下来是 mp4 / 解压提示已损坏
部分资源为过网盘审核会把压缩包伪装成 mp4（学习资料类最常见）。它不是视频，改个后缀就是正常压缩包：
认文件　文件列表里只有个别文件是 mp4（其余是 pdf 等），就是这种情况。
先下载　把 mp4 文件下载到电脑 / 手机本地，不要用网盘的在线解压。
改后缀　把 .mp4 改成 .zip 或 .rar，然后正常解压即可。
用百度网盘在线解压、或文件没下载完就解压，会提示「文件已损坏」——不是资源坏了，是解压方式不对。
缺字 系统缺日文字体，安装日文字体（MS Gothic / Meiryo）或转区运行
存档 常见于游戏目录下 save 文件夹，或 我的文档 / %APPDATA% 下以品牌命名的目录

快速定位

乱码 / 双击没反应 / 闪退 区域问题，用转区（Locale Emulator）运行
缺少 xxx.dll 装 VC++ 运行库 / DirectX
0xc000007b 运行库缺失或位数不匹配，补齐 VC++
解压 CRC 错误 文件损坏，重新下载
分卷解压失败 分卷没下全 / 不同目录，对第一卷解压
磁链没速度 做种少，换源或挂机等待
文字方框 / 缺字 缺日文字体，装字体或转区
转区工具被杀毒删除 误报，加信任或重新下载
下载是 mp4 / 已损坏 伪装后缀的资源，先下载到本地，改 zip 或 rar 再解压
报毒 / exe 消失 杀毒误报，关实时防护或加信任后重新解压
提示缺少 xxx.dll / 0xc000007b / 缺少运行库
多为缺少运行库：安装 Visual C++ 运行库（x86 + x64 都装）、必要时 DirectX 与 .NET，均见「游戏工具」。
0xc000007b 通常补齐 VC++ 运行库即可解决。
